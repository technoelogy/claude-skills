# # claude-skills 

Reusable Claude skills for digital marketing, brand strategy, and consumer health work. India-first lens. 

Built and used in production by [@technoelogy](https://github.com/technoelogy) across consulting engagements for OTC, D2C, pharma, and FMCG brands. 

# ## What's in here 

| Skill | What it does | Use for | 

- |---|---|---| 

| [brand-analysis](brand-analysis/) | Consulting-grade brand & digital audit framework (16 sections, India market) | Pitch prep, competitive teardowns, client onboarding | 

# ## How to use 

Each folder contains a `SKILL.md` file. Drop it into: 

- A Claude Project (as Project knowledge) 

- A Claude Code `.claude/skills/<skill-name>/` folder 

- Any system that reads skill files 

Then trigger the skill by its intent (see each SKILL.md for triggers).
